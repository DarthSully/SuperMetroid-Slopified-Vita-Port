2026-09-28. The owner subsequently approved integration.

Normal generation now reads `recomp/disassembly-layout.json`, containing
only addresses, instruction lengths, data boundaries and reference hashes.
The framework verifies the owned ROM and reconstructs the approved
authority overlay automatically, including the validated M/X probes.
The developer and launcher/CLI generation paths use the same input.
A fresh generation reproduces the complete approved analysis manifest;
both 6,000-frame routes reproduce the approved state/video evidence and
interpreter instruction counts against the current explicit fallback API.
No ROMs or generated instruction bytes are committed.

Entry variants include CPU M/X modes and mirrors, not unique functions. Finite
state/video comparisons and owner gameplay review do not prove whole-game or
audio waveform equivalence.
