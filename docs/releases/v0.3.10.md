# Super Metroid v0.3.10

Fixes a long attract-demo freeze caused by incorrect cleanup of stack arguments
in the shared recompiler. The guest could stop while the window kept running;
the fix preserves the original return address and the cleaned stack.

Validation includes 20,000- and 60,000-frame cold-boot attract runs without an
interpreter cap or scheduler bailout, plus nine before/after routes across
Super Mario World, A Link to the Past, Super Metroid and Mega Man X. All recorded
route evidence matches exactly; the Ceres route retains its existing APU
synchronization timeout in both arms. The owner approved the final play check.

This release supplies setup ZIPs for Windows x64, Linux x64, macOS arm64 and
macOS x64, with the portable build tools included. Extract the complete pack,
launch setup and select your own unmodified Super Metroid (Japan, USA) ROM.
The game is generated and built locally. No ROM is included.

Back up your existing settings and saves before changing release folders.
See `framework_pins.txt` for the exact dependency revisions.
