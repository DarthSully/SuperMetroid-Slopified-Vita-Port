Super Metroid now ships as a precompiled game on Windows x64, Linux x64,
macOS Apple Silicon and macOS Intel. Extract the download, select your own
unmodified Super Metroid (Japan, USA) ROM, and play. Linux users should start
`Launch.sh` inside the extracted folder.

The first-run Generate & rebuild wizard has been removed. Downloads no longer
include the recompiler, game source or compiler toolchain, and playing requires
no Python, Rust, CMake, compilation or toolchain download. The ROM remains
required and is never included.

All platforms build the same `sm-ju-precompiled-0.3.12` profile. Retains the
v0.3.11 dependency revisions and its progression, item-message, HDMA, Crab Maze
and persistent-state fixes, together with the existing widescreen and
presentation mods. Default gameplay, interpreter fallback and audio settings
are preserved.

Preserve your settings and guest SRAM when updating. Host snapshots require
matching runtime builds; start from guest SRAM when moving between versions.
macOS packages are ad-hoc signed, not notarized. Mother Brain, the final escape
and credits remain unvalidated; assisted room coverage is not a full playthrough.
