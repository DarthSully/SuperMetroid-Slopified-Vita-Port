# Super Metroid v0.3.11

Fixes four progression and recovery defects in the recompiled game:

- Item messages could corrupt inventory and permanently stop the guest. Morph
  Ball could set collected items to `0x00FF` instead of `0x0004`. Item processing
  and the message NMI wait now remain on the ROM scheduler across yields.
- Crab Maze could hang when a compiled enemy slope helper led execution into
  sprite data. The affected helper now uses the portable ROM interpreter.
- An HDMA wrapper mishandled inline call arguments during Ceres effects. The
  wrapper and its inline-argument consumer now execute their original ROM
  instructions and return, including the consumer's LoROM-mirror entry.
- Host savestates loaded in a fresh process could run reset over restored RAM.
  New default-LLE snapshots preserve the active CPU, scheduler continuation and
  SPC state. Legacy snapshots and suspended HLE fibers retain prior limitations;
  host snapshots require matching runtime builds. Ordinary guest SRAM is separate.

Includes the overlapping desktop-header include fix from PR #18 and a reusable
memory-assisted QA harness. The prior campaign entered all 261 accessible rooms,
revisited 255 Zebes rooms with diagnostic post-boss flags, acquired all 21 pickup
types, and completed Kraid, Phantoon and Ridley death sequences using explicit
health/phase assistance. Real save-station SRAM and host snapshots were loaded
in fresh processes, including a snapshot taken during an open pickup message.
Room jumps bypass traversal requirements; this is not an unassisted completion.
Mother Brain, the final escape and credits remain unvalidated.

Retains the v0.3.10 framework and launcher pins, including its attract-demo fix.
The release integration is regenerated and tested against those exact pins;
see `framework_pins.txt` for the dependency revisions.

Setup ZIPs are supplied for Windows x64, Linux x64, macOS arm64 and macOS x64,
with portable build tools included. Extract the complete pack, run setup and
select your own unmodified Super Metroid (Japan, USA) ROM. The game is generated
and built locally. No ROM or saved progress is included.
